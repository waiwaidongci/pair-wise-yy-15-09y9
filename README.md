# 离线赛鸽训放台

面向赛鸽棚的单页训放管理工具，纯前端 + localStorage，断网可用，刷新不丢数据。

## 功能模块

- **鸽棚总览**：在棚羽数、雌雄比、归巢率、有效平均速度、未归巢数、健康分布、进行中配对数、血统分布。
- **训放记录**：登记足环号、血统、日期、地点、空距、天气/风向、司放与归巢时间、飞行速度（按时间自动计算，可手填覆盖）、归巢健康、备注。
  - 同一赛鸽、同一日期、同一地点只允许一条「有效」成绩；
  - 更正或补报后，旧成绩自动转为「失效」并保留在台账中可随时查阅，记录间保留顶替关系；
  - 支持按血统、状态（有效 / 未归巢 / 失效）筛选。
- **未归巢提醒**：仅列出状态为「未归巢」的场次，按逾时排序，可直接补报归巢；未归巢**不计入速度排行与归巢率分子**，补报后自动进入排行并从提醒移除。
- **成绩排行**：仅统计有效归巢成绩，按分速降序，支持血统 / 距离段 / 地点筛选；每羽取最佳成绩上奖台，另可查看全部有效场次。
- **血统档案**：按血统筛选鸽群，单羽档案含健康状态更新、三代血统树（父母→祖父母→曾祖辈）、全部历史训放（含失效留档）、当前配对。
- **配对管理**：配对前强制校验——
  - 亲本任一为「异常」健康状态直接拒绝并说明；
  - 三代以内存在共同祖先（直系、全/半同胞、叔侄、堂表亲等）直接拒绝，并给出共同祖先足环号与双方血缘路径；
  - 成功/拒绝的每次判定均留档可查。

## 一致性保证

总览、记录、提醒、排行、档案全部由同一份状态（`src/lib/loft.ts` 中的派生函数）计算；血统筛选、状态筛选、当前页签等偏好与业务数据一同持久化到 localStorage，刷新页面后数据与筛选结果保持一致。

## 技术栈

React 19 + Vite 7 + TypeScript，无后端、无网络请求。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:62014
npm run build    # 产出 dist/
```

首次打开会写入一份内置演示数据（含有效成绩、未归巢、更正失效、健康异常、近亲拒配等场景），可在右上角「演示数据」重置或「清空」。
